# Security policy

## Reporting a vulnerability

Report vulnerabilities privately through GitHub Security Advisories: open
https://github.com/cybermavericx/Veilcode/security and choose
**"Report a vulnerability"**.

Do not open a public issue, pull request or discussion for a vulnerability.
Do not include real secrets in a report; describe them or use generated test
values instead.

## Supported versions

Veilcode is pre-alpha. Only the latest pre-release is supported. Older
pre-releases get no fixes.

## Scope

What Veilcode does and does not protect against is set out in the threat model,
`docs/SPEC.md` §11. Reports about issues the threat model lists as out of scope
(for example malware on the same machine, or secrets no detector recognises)
are still welcome, but may be treated as known limitations.
